## Incident and repair

Commit `a7595c5` widened text-effect hydration beyond the menu.
That change damaged shared startup behavior.
Effect Windows also referenced an undefined `PANEL_SELECTOR`.
The monochrome reset also overrode Effect Window panels.
The obsidian runtime discarded render errors during fallback.

Commit `df60c59` rolled back the release while the repair ran.
Commit `c9881d2` restored the feature with narrow hydration and explicit runtime errors.
The runtime now records VGPU errors in data attributes and logs the original error.

A stale Vite dependency cache also returned `504 Outdated Optimize Dep` locally.
Restart the managed development server before changing source when this response appears.
