# Effect Windows

An effect window is a living region in the document flow. Its content sets the minimum size.

Each effect chooses its own boundary and motion language. Some apertures flow. Terminal stays rectangular and stable.

Use this page to judge each effect in both palettes. Check long text, lists, motion, and narrow screens.
